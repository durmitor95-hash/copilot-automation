# Polyglot Languages Registry

Registracija 3 nova jezika sa syntax highlighting podrskom.

## PejicLang (.pej)
- Python-like sintaksa
- Idealno za početnike
- Čitljiv i deklarativan kod

## NexusLang (.nxs)
- Sistemski jezik
- Niska-nivoa kontrola memorije
- Visoke performanse

## NexusConfig (.conf)
- Konfigurativni format
- Kombinacija JSON i YAML
- Fleksibilna struktura
